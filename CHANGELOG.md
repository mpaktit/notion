# Changelog
All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning: [SemVer](https://semver.org/).

## [1.0.0] — 2026-10-02
### Added
- Core game: grid engine with interpolated rendering, combo system, 5 power-ups, golden apples, currency pickups, revive.
- 5 sectors (Low Orbit, Red Dunes, Asteroid Belt, Nebula Veil, Event Horizon) with unique hazards and procedural music.
- 5 modes: Endless, Daily Run, Blitz, Classic, Zen.
- 8 playable species with stats, abilities and passives; fragment system.
- Two-currency economy (Stardust, Void Crystals), daily Item Shop, Standard and Prime Cores with published odds and pity.
- Locker with 44 cosmetics (skins, trails, crowns, death FX, titles) and live previews.
- Season 1 pass (30 tiers, free + premium), daily missions with swap, 7-day login calendar, 13 achievements, Lab upgrades.
- Onboarding with a guaranteed Rare+ welcome core.
- PWA (manifest + service worker), signed versioned saves, backup/restore codes, strict CSP.
- Vitest unit tests, Playwright e2e smoke test, CI and GitHub Pages workflows.
